Architecture

MASAREN follows a clean separation between a FastAPI backend and a static frontend served directly from disk.

Frontend

  • index.html — Single-page application shell
  • static/app.js — Application logic (auth, routing, API calls, UI rendering)
  • static/styles.css — All styling, including light/dark mode variables

Backend

  • FastAPI application with JWT-based authentication
  • SQLite database (auto-created at startup)
  • AI verification endpoint for assessing impact evidence
  • RESTful API — all routes are prefixed with /api

Workflow

The end-to-end flow for creating and verifying impact:

  1. Login
  2. Seed Demo Data
  3. Create Organization
  4. Create Program
  5. Create Task
  6. Assign Task
  7. Submit Evidence
  8. AI Verification
  9. Impact Asset

Users submit evidence for assigned tasks. The system runs AI-based verification to assess authenticity and relevance. Verified submissions are minted as Impact Assets and reflected on the leaderboard, SDG impact tracking, and the user's Impact Passport.

Performance Measurement System

The PMS evaluates contributions across multiple dimensions and assigns a tiered rating.

Dimensions

  • Quality — Completeness, accuracy, and relevance of evidence
  • Consistency — Sustained participation over time
  • Impact — SDG alignment and measurable outcomes
  • Collaboration — Team engagement and peer feedback
  • Innovation — Novel approaches and problem-solving
