# Overview

This page represents the **professional impact profile of a media personnel member** inside MASAREEN.

The user is **not** simply a social profile.

They are a verified professional whose work is measured, archived, analyzed, scored, and transformed into an impact portfolio.

The profile becomes their digital CV, performance dashboard, historical archive, verification center, analytics page, and reputation system.

Think of it as:

* LinkedIn
* ResearchGate
* GitHub profile
* Google Scholar
* Creator Studio
* Analytics Dashboard

combined into one professional profile.

# UX Principles

The implementation should preserve only the **structural concepts** demonstrated in the reference image:

* Prominent profile header.
* Large professional summary card immediately below the header.
* Clear KPI blocks.
* Tabbed navigation separating profile domains.
* Strong information hierarchy.
* Analytics positioned as first-class content rather than hidden behind menus.
* Card-based layout with generous spacing.
* Easy scanning of professional metrics.
* Responsive alignment across desktop, tablet, and mobile.

Do **not** reproduce the visual identity of the reference. Instead, implement the interface entirely with MASAREEN's established design language, components, branding, typography, iconography, color palette, motion system, and accessibility standards so that it feels like a native MASAREEN experience rather than a redesigned copy.
